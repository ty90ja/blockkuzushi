# 背景画像について

このフォルダに **`bg.jpg`** という名前で画像ファイルを置くと、
ゲームの背景として使用されます。

## 差し替え方法

1. 使用したい画像を `bg.jpg` という名前にする
2. この `images/` フォルダに配置する
3. GitHub にコミット & プッシュする

## 推奨サイズ・形式

- **縦長** の画像が最適 (例: 480×792 px)
- JPEG / WebP / PNG どれでも可
- ファイルサイズは 1MB 以下を推奨 (モバイル通信への配慮)

## 画像が見えてくるしくみ

ブロックが破壊されるたびにそのセルの背景が透けて見える仕組みです。
全ブロックを壊すと全体が表示されます。
